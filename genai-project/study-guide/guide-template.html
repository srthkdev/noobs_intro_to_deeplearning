What are we trying to do?

A factory camera photographs a long strip of material. We want to locate defective pixels and identify their defect category. Predicting only “defective image” would not tell the factory where the problem is. Segmentation gives a pixel-level answer.

The dataset has 11,393 labelled images and four anonymized labels: defect_a, defect_b, defect_c and defect_d. An image can be clean or contain several categories. The final models take one grayscale channel; the RGB Milestone 2 exercise is a separate baseline.

03 · Understand the data

Images, masks
and a lot of background.

A model learns from the targets we give it. Decode one annotation properly before thinking about a bigger network.

One image versus four pairs

An image has four target channels. An image–class pair means one image considered for one defect type. A clean image contributes four empty pairs.

The full training set has 45,572 pairs: 7,201 positive and 38,371 empty.

Why imbalance matters

5,516 images are completely clean. Defect B appears in only 313 images. Most pixels are background even in a defective image.

A model can lower loss by learning background first. High pixel accuracy does not prove that it finds defects.

Actual full-dataset class presence. Counts overlap across classes.

Before reading the bars

EDA means exploratory data analysis: inspect labels and images before fitting a model. The horizontal categories are defect types; bar length counts images containing each type. A longer bar means more examples, not worse defects or better predictions. Counts can overlap because images can have several labels.

The EDA we actually did

RLE: store runs, not every pixel

Run-Length Encoding stores positive runs in a flattened mask. Our format starts at 1 and scans down each column. For zero-based row r and column c, the flattened position is r + c × H + 1.

U-Net skip versus ResNet residual
A U-Net skip carries encoder features to the decoder and typically concatenates them. A ResNet residual shortcut adds a block’s input to its transformed features inside the encoder. They are different connections.
Why four sigmoid outputs?
Each defect gets its own probability; background means all four are absent. A five-class softmax including background is another formulation, but our code uses four independent binary outputs.
Grayscale and pretrained weights
The pretrained encoders originally expect RGB. With in_channels=1, SMP 0.5.0 sums the pretrained first convolution’s three input-channel weight slices into one. The segmentation decoder is initialized for this task.



05 · Watch learning happen
What one epoch
actually means.
A batch is a small group processed together. An optimizer step updates weights. An epoch finishes one pass through the training loader.
Batch → forward → loss → backward → update
The forward pass produces logits. Loss measures disagreement with masks. Backpropagation computes gradients. AdamW uses them to update weights.
Actual final batch size: 16. The sampler draws with replacement, so an epoch is the configured number of draws, not a guarantee that every unique image appears once.

06 · Read predictions properly
Overlap, false alarms
and misleading accuracy.
Understand the score components before trusting one number.
Dice measures overlap
Dice = 2 × intersection / (predicted area + target area)
Equivalently, 2TP / (2TP + FP + FN). A perfect match is 1; a missed positive mask is 0.
Dice and F1 share this binary formula, but mean pair Dice and globally accumulated pixel F1 can differ because they average differently.
The all-empty trap
About 84.2% of full-dataset image–class pairs are empty. Predicting empty everywhere gets naive Dice about 0.842 while finding no defects.
Its official-style score is only 0.300: foreground Dice 0, FalsePositiveScore 1 and EmptyAccuracy 1.
Build the weighted score
0.70 × foreground Dice + 0.20 × FalsePositiveScore + 0.10 × EmptyAccuracy
Final code computes a score per class and averages classes. M4’s subset/toy exercise pools pairs. Same weights, different aggregation.
Three pixel-level outcomes
A true positive (TP) is a pixel labelled defective that we also predict as defective. A false positive (FP) is a good pixel we incorrectly flag. A false negative (FN) is a labelled defect pixel we miss. Dice rewards overlap and penalizes the last two. Background pixels correctly left alone do not appear in its numerator.

A precise limitations answer
